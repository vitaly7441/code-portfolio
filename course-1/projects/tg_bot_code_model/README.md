## Описание проекта

Проект **Телеграм‑бот AI** — это бот, который принимает текстовые сообщения пользователя и, взаимодействуя с OpenRouter, выдаёт ответ пользователю, при этом сохраняя всю историю диалога в отдельный файл.

## Реализованные функции

- Обработка текстовых сообщений от пользователя.
- Взаимодействие с API OpenRouter для генерации ответов.
- Сохранение полной истории диалога в локальный файл. 
* Реализованные команды:
    - `/start` — начало работы(приветственное сообщение).
    - `/help` — отобразить все доступные команды.
    - `/stats` — статистика чата (сообщения, токены).
    - `/clear` — очистить историю переписки.
    - `/summarize` — краткий пересказ диалога.
    - `/undo` — удалить последнее сообщение.
    - `/joke` — сгенерировать шутку.
